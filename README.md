# anagalicportfolio.com

Ana Galic's portfolio site, served by GitHub Pages.

- `index.html` is the whole site: every page lives in this one file.
- `img/` holds the images.
- `404.html` sends old Framer links (like `/work/peaceland`) to the matching new page.
